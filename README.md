# Page web pour le planning des maraudes "Papillons de Nuit"

> La page est en ligne à l'addresse : xxx.com

**Pour modifier le calendrier** 

Il suffit de mettre à jour le fichier suivant : [src/pages/acceuil-calendrier.md](src/pages/acceuil-calendrier.md)

1/ cliquer sur le lien ci-dessus. Une page avec le contenu "brut" du fichier s'affiche

2/ Cliquer sur l'icone "stylo" en haut à droite et faire les modifications voulues en respectant le format ci-dessous

```
---

▶ Le XXXXX 00/0/2026

*detail sur le lieu et l'heure*

---

```

3/ Pour sauvegarder, cliquer sur le bouton "commit changes ..." en haut à droite. une fenêtre pop-up s'affiche.

4/ Re-cliquer sur ce même bouton et voila ! La page web se met à jour automatiquement après quelques minutes.
